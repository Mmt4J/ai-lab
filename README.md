# AI Lab

## Overview
AI Lab is an AI-powered application that
provides productivity tools for processing
text, analyzing customer support tickets,
and generating product descriptions.

## Features
- Text Summarization
- Support Ticket Classification
- Product Description Generator
- FAQ Chatbot
- Receipt and Invoice Reader
- Review Sentiment Analysis

## Technologies
- Laravel
- Livewire
- Alpine.js
- Tailwind CSS
- MySQL
- Groq AI

## Requirements
- PHP 8.3+
- Composer
- Node.js and NPM
- PosgreSQL

## Installation
1. Clone the repository.
2. Install dependencies.
3. Configure your environment.
4. Generate application key.
5. Run migrations.
6. Build frontend assets.

## Running the application

php artisan serve
